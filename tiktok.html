How the app uses TikTok

"Iris Two Eyes" is a small publishing tool. It is used only by Iris's creator, to publish Iris's episodes to Iris's own TikTok account. No other person signs in to it.

Login Kit

The creator signs in once with TikTok and approves the app. TikTok then sends an authorization code to our redirect page (callback.html on this website). The tool exchanges it for an access token.

  • user.info.basic: used to show which account is connected (display name and avatar) before publishing.

Content publishing (Content Posting API)

  • video.publish: the tool uploads an MP4 episode, asks TikTok which privacy options the account allows, and checks the publishing status.
  • video.upload: included with the Content Posting API; not used on its own.
  • Every video is labelled as AI-generated content.

What is stored

  • The access token, the account's open ID and the display name. They are stored privately on the creator's own computer. They are never published.
  • Nothing about other TikTok users or viewers is collected, stored or shared. This website sets no cookies and has no tracking.

How to revoke access

In the TikTok app: Profile → Menu → Settings and privacy → Security & permissions → Manage app permissions, then choose "Iris Two Eyes" and remove it. The stored token is then deleted. You can also write to Write to us.
