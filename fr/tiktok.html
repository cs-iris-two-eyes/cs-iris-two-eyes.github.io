Comment l'application utilise TikTok

« Iris Two Eyes » est un petit outil de publication. Seul le créateur d'Iris l'utilise, pour publier les épisodes sur le compte TikTok d'Iris. Personne d'autre ne s'y connecte.

Login Kit

Le créateur se connecte une fois avec TikTok et approuve l'application. TikTok envoie alors un code d'autorisation à notre page de retour (callback.html sur ce site). L'outil l'échange contre un jeton d'accès.

  • user.info.basic : sert à afficher le compte connecté (nom et avatar) avant de publier.

Publication de contenu (Content Posting API)

  • video.publish : l'outil envoie un épisode MP4, demande à TikTok les options de confidentialité permises, et vérifie l'état de la publication.
  • video.upload : inclus avec la Content Posting API ; non utilisé seul.
  • Chaque vidéo est signalée comme contenu généré par IA.

Ce qui est stocké

  • Le jeton d'accès, l'open ID du compte et le nom affiché. Ils restent sur l'ordinateur du créateur. Ils ne sont jamais publiés.
  • Rien sur les autres utilisateurs ou spectateurs TikTok n'est collecté, stocké ou partagé. Ce site n'utilise ni cookie ni traceur.

Comment révoquer l'accès

Dans l'application TikTok : Profil → Menu → Paramètres et confidentialité → Sécurité et autorisations → Gérer les autorisations des applications, puis choisissez « Iris Two Eyes » et retirez-la. Le jeton stocké est alors supprimé. Vous pouvez aussi écrire à Écrivez-nous.
